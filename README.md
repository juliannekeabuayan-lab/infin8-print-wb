# INFIN8 PRINT — Interactive Website

A responsive static website for INFIN8 PRINT, built with HTML, CSS and vanilla JavaScript.

## Included
- INFIN8 PRINT logo supplied as a PDF, converted to a transparent PNG for the website.
- Product showcase images cropped from the supplied website reference.
- Red, black and white brand styling with responsive mobile navigation.
- Service pricing retained from the supplied reference website.
- Searchable service cards and category filters.
- Click-to-enlarge showcase gallery.
- Quick inquiry / contact forms that prepare a WhatsApp message to **0999 305 0039**.
- Google Maps, Facebook, email and Viber links.
- Scroll reveal effects and back-to-top control.

## Preview locally
Open `index.html` in a browser. For best results, run a local static server from this folder (for example, VS Code Live Server).

## Deploy to Vercel
1. Extract the ZIP.
2. Upload the contents of this folder to a GitHub repository.
3. Import the repository at https://vercel.com/new.
4. Use the default static deployment settings. No build command is required.

## Before publishing
- Confirm all prices are still current; they were retained from the supplied reference website.
- The contact and estimate forms open WhatsApp with a prefilled message. They do not store orders or send messages automatically.
- Confirm the phone number, email, Facebook page and Google Maps link.
- The product showcase photos are taken from the supplied reference screenshot. Replace them with original high-resolution product photos when available.
- Google Fonts requires an internet connection; system sans-serif fallbacks are included.
